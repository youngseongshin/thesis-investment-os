# Three-Agent Model

This path is retained for compatibility.

The executable public core still exposes three primary roles: Alpha for
evidence, Lattice for judgment, and Arki for control-plane work. The complete
reference architecture now distinguishes five durable operating roles by also
including Gwajang for VC/private-company work and Claw for personal context.

Read [Operating Roles](operating-roles.md) for the current ownership model and
[System Whitepaper](system-whitepaper.md) for the control architecture.

The rule has not changed: add a role only when it preserves a real data,
decision, confidentiality, or permission boundary. Specialist and red-team
work should usually remain bounded workers rather than new persistent agents.
